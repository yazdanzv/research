# Compare_Multiple_DL_Methods_on_Flight_USA_Dataset

## Code guide

`main.ipynb` is the analysis entry point. It loads the flight data, handles categorical values and missing data, visualizes features, applies scaling and PCA, then compares learning methods. The notebook imports pandas, NumPy, scikit-learn, Matplotlib, Seaborn, TensorFlow/Keras, and `hpelm`. `Report.pdf` contains the written report. Run notebook cells in order after providing the dataset paths used in its loading cells; the repository does not provide a one-command environment setup.
